# Pothole model weights

Place your trusted trained pothole model here as `best.pt`.
Weights were not available in the imported project files and are intentionally
excluded from Git. Do not substitute the corn-leaf model.

Before distributing a model, document its source, license, class order, input size,
model version, SHA-256 checksum and measured validation results. Do not claim
accuracy from a detection confidence threshold.

Only load trusted weights. Use an approved model download location or configure
Git LFS deliberately if the team chooses to version weights. No download link or
checksum is supplied here because no authoritative model artifact was provided.
